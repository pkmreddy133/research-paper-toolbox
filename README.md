# Research Paper Toolbox

COM321 Sustainable Information Structure Project - Praveen Maramreddy

A learning website with lessons on finding research resources and organizing research data.

## Opening the website

Download and extract the project, then open `index.html` in a browser.

## Files and folders

- `index.html`: home page and links to all modules.
- `modules/research.html`: Research lesson.
- `modules/data.html`: Data lesson.
- `modules/placeholder.html`: shared placeholder for the six remaining modules.
- `modules/template.html`: examples of the structures used to build a lesson.
- `css/styles.css`: stylesheet shared by every page.
- `images/`: lesson screenshots.
- `downloads/`: spreadsheet for the Data lesson.

## Adding a module

1. Copy `modules/template.html` to a new file in the `modules` folder.
2. Update the page title, description, headings, and lesson content.
3. Update the section IDs and matching links in the lesson contents menu.
4. Use the template examples for lists, sidebars, figures, and captions.
5. Keep the shared stylesheet link. Update the navigation on every page and the module list on the home page to include the new module.
6. Validate the HTML and check that the links and images work.
